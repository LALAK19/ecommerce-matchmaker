# 🛍️ E-Commerce Product Matchmaker

An intelligent recommendation algorithm designed to match users with e-commerce products based on personalized interest tags and preferences.

---

## 🌟 Key Features
- **Smart Tag Matching**: Evaluates user preferences against product metadata.
- **Scored Ranking**: Ranks top recommendations dynamically by relevance score.
- **Extensible & Lightweight**: Easy to integrate into any e-commerce workflow or API backend.

---

## 🚀 Quick Start

### Run Locally
```bash
python ecommerce_match.py
```

### Example Output
```text
Finding matches for preferences: ['tech', 'fitness']...

Top Matches Found:
- Smart Watch (Match Score: 2)
- Wireless Headphones (Match Score: 1)
```
